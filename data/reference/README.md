# Reference data

No third-party papers or source archives are currently stored here. The source
ledger in `docs/bibliography.md` records stable identifiers and retrieval date.

Before adding a snapshot, record its upstream URL, version or commit, retrieval
timestamp, SHA-256 hash, license, and purpose. Treat the snapshot as read-only.

Store authenticated, read-only research inputs here when their licenses permit
redistribution. Record provenance, retrieval information, and SHA-256 hashes.
Do not edit third-party data in place.
