## Selection rationale

`x < y`, `OneChangeOn` constrains the word

```text
[chi(q,r,x), chi(q,r,y), chi(q,x,y), chi(r,x,y)].
```

When the last two colors agree, equality of the first and third colors is
absorbing: the second color must agree as well.  Common strong extensions give
the needed last-color equality away from the unique first-middle defect; the
existing exact dichotomy makes the complementary defect branch constant
already.  This is mathematically different from requiring the raw pair word
itself to have one switch, and the Cycle-008 table satisfies rather than
refutes it.  Whether this base-relative law has a current gluing consumer is
unknown.

The failed table is only an abstract ordered coloring.  The exact destination

rank-three/realizability axiom rather than assuming the model gap matters.  It
may only report a literal local obstruction or a precise no-distinguishing-law

abstract law failed.
