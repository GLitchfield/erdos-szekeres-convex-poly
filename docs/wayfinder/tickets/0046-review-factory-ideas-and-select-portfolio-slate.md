# Ticket 0046: review factory ideas and select a portfolio slate

## Question

Which Batch 004--005 proposals, if any, deserve admission into the canonical
frontier portfolio, and what presently executable portfolio slate should be
offered for approval without padding to four?

## Decision criteria

For every factory proposal, decide whether to merge it into an existing stable
family, admit a new family with the complete portfolio schema, retain it only
in the idea ledger, or expire it.  A proposal cannot reset a correlated
family's negative streak merely by changing vocabulary.  Admission requires a
named destination consumer, explicit model tier and scope ceiling, honest
missing bridge, bounded discriminating gate, and an expiry or revival rule.

Selection occurs only after portfolio validation.  A slate must label
proof-producing and information-gathering work, identify mechanism-level
correlations, normally use no more than two slots from one family, and explain
why each selected gate is executable now.  Four is a capacity target, not a
quota.  Any addition, revival, or material redirection must survive the
repository's bounded Sol/Fable adversarial review.  This ticket authorizes
review and planning only, not execution of a selected slate.

## Resolution

Outcome: `PORTFOLIO-READINESS-GAP`.

Admit none of the ten Batch 004--005 proposals into the canonical portfolio.
Retain all ten in the append-only idea ledger as uninvestigated proposals:

- B004-I01, B005-I01, and B005-I02 do not revive the suspended
  predecessor-half family.  Their finite panels remain useful falsifier ideas,
  but proposal-only evidence does not satisfy `FP-07`'s positive-mechanism
  revival rule.  B004-I02 remains an untested balancedness card and is not a
  negative control.
- B004-I03 does not reopen completed `FP-15`: it lacks a theorem-shaped exact-
  route consumer beyond the published quantitative ceiling.
- B004-I04 remains a finite flag-SOS feasibility proposal.  It supplies no
  required induction base or parameterized consumer beyond `D-UPPER(7)`, so it
  does not become `FP-16.B`.
- B004-I05 leaves the load-bearing cardinality work inside an independent
  binary Morse bound.
- B005-I03 does not become `FP-17`: a Monge law alone does not strictly reduce
  the already recorded endpoint-synchronization obligation.
- B005-I04 moves `D-NORMALIZE` into an unproduced deep-tangle exclusion and
  does not revive `FP-04`.
- B005-I05 supplies canonical machinery but no theorem producing geometric
  relevance to `D-HALF` or `D-DECOMP`.

The preliminary four-slot slate is rejected.  Three slots depended on those
unsupported admissions.  The review finds one currently frozen executable
portfolio gate: `FP-14.B` may attempt the unchanged Fin11 leaf using a
streaming or balanced checkpoint architecture below 12 GiB.  It is
proof-producing only if the Lean theorem compiles; otherwise it is operational
certificate work on a suspended mathematical parent.  The packet identifies
no second executable gate with satisfied dependencies and required prior
reviews.  Therefore this ticket selects no padded four-thread slate.  The next
user decision is between a one-slot `FP-14.B` run and a separate route-grounding
block that first freezes legitimate theorem or falsifier cards.
