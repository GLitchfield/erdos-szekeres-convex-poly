## Resolution

The user explicitly requested a Fable-5.1 trial.  Official Google Cloud
documentation retrieved 2026-09-01 confirms release date 2026-09-01 and exact
model ID `claude-fable-5-1`.  Root froze one 209,649-byte packet asking about:

1. a uniform separated-owner obstruction for placements `03/04/13/14`;
2. proposition-level compression of actual dual transports `23/24/34`; and
3. the first strict matching-tag router theorem before the three-owner closure.

The direct one-shot harness used `claude-fable-5-1` and independent control
`gpt-5.6-sol`, zero reciprocal rounds, a 1,200-second per-provider timeout,
and no retry or fallback.  Fable stopped before inference because installed
Claude Code `2.1.235` does not support the model and the server requires
version `2.1.251` or newer.  Its envelope records zero input tokens, zero
output tokens, and zero cost.  The packet did not authorize software updates,
so root did not run `claude update` or attempt a second identity.

The Sol control completed with a citation-valid `partially_supported` advisory
review.  It ranks the matching-tag router highest in uniform leverage but says
its placement classifier remains the missing producer; it finds no justified
compression theorem for the contradiction or dual families and recommends
placement `13` as the cheapest next check.  Because Fable returned no
mathematical output, this is Sol-only proposal evidence, not reciprocal review
or provider consensus.
