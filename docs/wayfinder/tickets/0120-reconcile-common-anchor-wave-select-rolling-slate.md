# Ticket 0120: reconcile the common-anchor wave and select its bounded rolling successor

## Question

After Ticket 0119 released the self-refilling service and a root mathematical
wave exposed common-anchor structure, which results are admissible, is any
load-bearing obligation smaller, and what is the smallest honest rolling slate?

## Decision criteria

1. Admit only compiling theorems, independently checked exact computations, or
   precisely scoped symbolic/source proposals at their actual evidence tier.
2. Charge each negative to the narrowest tested representation or candidate and
   preserve it in exactly one `FP-01` failure genome.
3. Do not call the adaptive `7 -> 4` witness-family normalization forward proof
   movement unless its full-context successor is demonstrably smaller.
4. Keep the scheduler stopped unless its implementation/authorization drift is
   separately diagnosed and repaired.
5. Select no more than the executable mathematical gates; use spare capacity
   for queue readiness rather than padding the slate.
6. Keep `native_decide` evidence computational and use only the guarded
   Makefile path for Lean integration.
