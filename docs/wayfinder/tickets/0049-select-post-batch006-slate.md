# Ticket 0049: select the post-Batch-006 execution slate

## Question

Which four executable children, if four honestly qualify, should form the next
temporary research slate after Ticket 0048's portfolio reconciliation?

## Decision criteria

Selection does not change portfolio membership or approve execution. Every
slot needs a precise bounded gate, outcome branches, a stable parent mechanism,
and an honest evidence label. At most two slots may come from one mechanism
family absent an explicit mathematical justification. A nominally gated entry
whose current contract says that no gate is scheduled is ineligible until its
revival condition is met. If fewer than four cards survive review, reduce the
slate rather than pad it.

The root preliminary slate is frozen at
`runs/agents/20260820-post-batch006-slate-selection/preliminary-slate.md`.

a high-confidence `partially_supported` review. Claude Fable again returned
HTTP 429 with zero input and output tokens; this is an operational limitation,
not a mathematical vote. Because the surviving review recommends only a
strictly smaller conservative slate and no route addition or revival, the
failure is recorded without manufacturing reviewer agreement.
