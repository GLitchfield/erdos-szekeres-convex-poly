## Current proof idea and exact missing obligation

The intended proof is fixed-budget size induction on a decomposable root.
The accepted DS law and ordinary separated/non-tight cases close every
root except the following exact ROOT obligation or its cup/cap dual.
There is no proved induction invariant or global constructor for that step.

Put s=k-1. Let beta>=4,p=s-beta>=1,m=alpha-p>=3. Nonempty
parts A,B form a deep-below root X=A<<B and satisfy

- c(A)=p,c(B)=alpha,d(B)=d(X)=beta,sigma(X)<=s;
- a valid B partition on p,...,alpha-1 is supplied, with
  c(B_j)<=j+1,d(B_j)<=s-j;
- a maximum beta-cap of X meets BOTH A and B. This implies strict core
  contraction, but pure-only contraction is a closed case by paper81.

**Construct a valid partition of X on those SAME bands. All points may
change bands, and A need not all enter bottom.** Mixed cups imply c(X)=alpha.
Full BDL implies this mixed ROOT; the written size induction,
duality, cap3 boundary and no-mixed-maximum construction conversely show
it suffices for BDL. This is the
minimal residual for the accepted reduction, not a compiling theorem.
See BDL-CORE-REDUCTION.md for the complete conditional proof.

The geometry is exact: every maximum beta-cap of B strictly encloses ALL A,
d(A)<=beta, and d(B inside open span(A))<=beta-2. Together these are
equivalent to retained cap beta. A is classic; the DS join p+beta=s
makes sigma(X)=s EXACTLY. Bounds after shifting labels by p are
c(X_h)<=p+h+1,d(X_h)<=beta-h, h=0,...,m-1,3<=m<=beta.
The additional mixed condition is equivalent to at least one equality:
d(B_<maxA)=beta-1, d(B_>minA)=beta-1, or, if |A|>=2,
d(B intersect span(A))=beta-2. The retention hypotheses bound these
ranks above, and each threshold supplies a one/two-A-endpoint cap.
The failure is exactly the possible p+2 cup using two upper endpoints,
one beyond the bottom limit p+1.

If a child bottom C has c(C)<=p+1, adding ALL A there is valid exactly when
c(A inside open span(C))<=p-1. Full-core BRL+ positions bottom wholly
before the max-cap core's left end OR after its right end and is a
stronger sufficient route. It is not logically necessary for an arbitrary
ROOT/BDL proof. Neither normalization nor realignment is proved.
